Tentang Website

Website ini membahas tiga teknologi yang banyak digunakan pada era digital, yaitu Internet of Thiings (IoT), Big Data dan Cloud Computing. IoT menghasilkan data,Big Data mengolah dan menganalisis data, sedangkan Cloud Computing menyediakan sumber daya komputasi dan penyimpanan melalui internet.

Absolut URL

Absolut URL adalah alamat lengkap yang digunakan untuk menuju suatu halaman atau sumber di internet. Contohnya: Google.

Relative URL

Relative URL adalah alamat yang digunakan untuk menghubungkan halaman atau file yang berada di dalam website yang sama.

Contohnya adalah IoT

Kesimpulan: Absolut URL digunakan untuk mengakses alamat lengkap di internet, sedangkakn Relative URL digunakan untuk menghubungkan dalam website sendiri
