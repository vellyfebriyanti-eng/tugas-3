CLOUD COMPUTING

Cloud Computing adalah teknologi yang memungkinkan pengguna menggunakan berbagai sumber daya komputer melalui internet.

Pengertian Cloud Computing

Dengan Cloud Compputing, penggunaan tidak harus menyimpan seluruh data dan menjalankan seluruh aplikasi hanya pada komputer pribadi. Data dan sumber daya komputer dapat disediakan melalui internet, sehingga pengguna dapat mengaksesnya dari berbagai perangkat selama terhubung ke jaringan Contoh layanan Cloud Computing yang sering digunakan dalam kehidupan sehari hari adalah Google DRive, Google Docs, Microsoft OneDrive, dan Dropbox. Layanan tersebut memungkinkan untuk menyimpan, mengolah, dan mengakses data secara online tanpa harus bergantung sepenuhnya pada penyimpanan komputer.

Manfaat Cloud Computing

Cloud Computing memungkinkan pengguna untuk mengakses data dari berbagai perangkat selama memiliki koneksi internet. teknologi ini juga memudahkan pengguna dalam berbagi file dan melakukan pekerjaan secara kolaboratif.

Hubungan dengan Teknologi Lain

Cloud Computing dapat digunakan untuk menyimpan dan memproses data yang dihasilkan oleh IoT. Data dalam jumlah besar tersebut juga dapat dianalisis menggunakan teknologi Big Data. Oleh karena itu, Iot, Big Data, Cloud Computing dapat salig mendukung dalam membangun sistem teknologi modern.
